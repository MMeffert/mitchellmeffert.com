<task type="auto">
  <name>Task 2: Add accessible focus styles</name>
  <files>css/style.css</files>
  <action>
Add a new focus styles section in the CSS custom properties area (after the :root block, around line 88).

Add these custom properties to the :root block first:
```css
    /* Focus */
    --color-focus: #005fcc;
    --color-focus-light: #fff;
```

Then add this section after the :root block:
```css
/*======================
    Focus Styles
========================*/

/* Default focus style for interactive elements */
a:focus-visible,
button:focus-visible,
input:focus-visible,
select:focus-visible,
textarea:focus-visible,
[tabindex]:focus-visible {
    outline: 3px solid var(--color-focus);
    outline-offset: 2px;
}

/* Focus on dark backgrounds (hero, funfacts, cta, testimonials) */
.home-bg a:focus-visible,
.home-bg button:focus-visible,
.bg-funfact a:focus-visible,
.bg-funfact button:focus-visible,
.bg-cta a:focus-visible,
.bg-cta button:focus-visible,
.bg-client a:focus-visible,
.bg-client button:focus-visible,
.bg-dark a:focus-visible,
.bg-dark button:focus-visible {
    outline-color: var(--color-focus-light);
}

/* Navbar focus - adapt to sticky state */
.custom-nav a:focus-visible {
    outline-color: var(--color-focus-light);
}

.custom-nav.stickyadd a:focus-visible {
    outline-color: var(--color-focus);
}
```

Use `:focus-visible` (not `:focus`) so focus rings only appear during keyboard navigation, not mouse clicks. This is the modern accessible approach - visible for keyboard users, hidden for mouse users.
  </action>

4. Tab through hero section - focus should be light colored (visible on dark bg)
5. Tab through regular sections - focus should be blue (visible on light bg)
  </verify>
