<task type="auto">
  <name>Task 1: Extract colors to CSS custom properties</name>
  <files>css/style.css</files>
  <action>
Add a :root block at the top of style.css (after the @import statement) defining semantic CSS custom properties for all hardcoded color values.

**Color inventory to extract (with semantic names):**

Primary/Brand:
- `--color-primary: #000` (black - the brand/accent color)
- `--color-primary-rgb: 0, 0, 0` (for rgba usage)
- `--color-on-primary: #fff` (text on primary backgrounds)

Background:
- `--color-background: #fff` (page background)
- `--color-background-light: #f8f9fa` (card/tag backgrounds)
- `--color-background-input: #f1f1f1` (input field background)

Text:
- `--color-text: #000` (primary text)
- `--color-text-muted: #777` (secondary/muted text - Note: Phase 10 will fix contrast)
- `--color-text-description: #666` (description text)
- `--color-text-light: #9a9a9a` (lightest text - Note: Phase 10 will fix contrast)
- `--color-text-separator: #bbb` (separator markers)
- `--color-text-input: #4c5667` (form input text)

Text on dark backgrounds:
- `--color-text-on-dark: #fff` (white text on dark backgrounds)
- `--color-text-on-dark-rgb: 255, 255, 255` (for rgba usage)

Borders:
- `--color-border: #e7e7e7` (standard borders)
- `--color-border-strong: #d0d0d0` (emphasis borders)
- `--color-border-dashed: #b9b9b9` (dashed borders)
- `--color-border-social: #868e96` (social icon borders)

Status:
- `--color-success: #0dba26` (success messages)
- `--color-error: red` (error messages)

Legacy (keep for reference, may remove later):
- `--color-link-legacy: #337ab7` (Bootstrap-style link color)

Special (used sparingly):
- `--color-dot: #757575` (about section dots)
- `--color-sidebar-link: #303133` (sidebar link text)
- `--color-selection: rgba(166, 175, 189, 0.3)` (text selection)
- `--color-gradient-start: rgba(18, 166, 181, 0.8)` (gradient overlay start)
- `--color-gradient-end: rgba(16, 12, 242, 0.7)` (gradient overlay end)

**Then replace ALL hardcoded color values throughout the file with var() references:**

Examples of replacements:
- `background-color: #fff;` -> `background-color: var(--color-background);`
- `color: #000;` -> `color: var(--color-text);` or `var(--color-primary);` depending on context
- `color: #777;` -> `color: var(--color-text-muted);`
- `color: #ffffff;` -> `color: var(--color-text-on-dark);`
- `border: 1px solid #e7e7e7;` -> `border: 1px solid var(--color-border);`
- `background: rgba(0, 0, 0, 0.7);` -> `background: rgba(var(--color-primary-rgb), 0.7);`

**Context-sensitive naming:**
- Use `--color-primary` when black is used as the brand/accent color (buttons, active states)
- Use `--color-text` when black is used for body/heading text
- Use `--color-background` when white is used as background
- Use `--color-text-on-dark` when white is used as text on dark backgrounds

**Do NOT change:**
- CSS structure or selectors
- Any non-color properties
- The @import statement at the top
- Comments structure

**Preserve !important flags** where they exist.

<task type="auto">
  <name>Task 2: Add responsive breakpoints</name>
  <files>css/style.css</files>
  <action>
Add media query breakpoints for tablet (992px), large desktop (1200px), and extra-large (1400px) to complement the existing 768px mobile breakpoint.

**Current state:** Only one breakpoint at `@media (max-width: 768px)`

**Add breakpoints using mobile-first approach where appropriate:**

1. **Tablet breakpoint (max-width: 992px):**
   - Navbar transitions earlier on larger tablets
   - Grid layouts adjust (2-column instead of 3)

2. **Large desktop (min-width: 1200px):**
   - Increase section padding for more breathing room
   - Allow larger max-widths for content containers

3. **Extra-large screens (min-width: 1400px):**
   - Further increase max-widths
   - Enhance typography scale slightly

**Specific additions:**

```css
/* Tablet breakpoint */
@media (max-width: 992px) {
    .header_title {
        font-size: 54px;
    }
    .header_subtitle {
        font-size: 16px;
    }
}

/* Large desktop */
@media (min-width: 1200px) {
    .section {
        padding-top: 100px;
        padding-bottom: 100px;
    }
    .about-detail {
        max-width: 900px;
    }
    .section-main-title {
        max-width: 650px;
    }
}

/* Extra-large screens */
@media (min-width: 1400px) {
    .section {
        padding-top: 120px;
        padding-bottom: 120px;
    }
    .about-detail {
        max-width: 950px;
    }
    .header_title {
        font-size: 80px;
    }
}
```

Place these new media queries in the RESPONSIVE section (section 18) of the CSS, before the final smooth scrolling section.

**Use custom properties for any color values** in new media query rules (though breakpoints typically don't change colors, just spacing/sizing).
  </action>

Test at 1400px viewport - further refinements visible
  </verify>
