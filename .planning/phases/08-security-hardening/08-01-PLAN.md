<task type="auto">
  <name>Task 1: Scope Lambda SES permissions</name>
  <files>cdk/lib/static-site-stack.ts</files>
  <action>
Update the Lambda SES policy (lines 169-174) to scope permissions:

1. Remove `ses:SendRawEmail` action (contact form only uses SendEmail, not MIME-formatted emails)
2. Replace `resources: ['*']` with identity-scoped ARN

Change from:
```typescript
this.contactFormFunction.addToRolePolicy(
  new iam.PolicyStatement({
    actions: ['ses:SendEmail', 'ses:SendRawEmail'],
    resources: ['*'],
  })
);
```

Change to:
```typescript
this.contactFormFunction.addToRolePolicy(
  new iam.PolicyStatement({
    actions: ['ses:SendEmail'],
    resources: [
      `arn:aws:ses:${this.region}:${this.account}:identity/mitchellmeffert.com`
    ],
  })
);
```

The domain identity `mitchellmeffert.com` is what's verified in SES (not individual email addresses).
  </action>
  <verify>
Run `grep -A5 "ses:SendEmail" cdk/lib/static-site-stack.ts` shows:
- Only `ses:SendEmail` action (no SendRawEmail)
- Resource contains `identity/mitchellmeffert.com` (no `'*'`)
  </verify>
  <done>Lambda SES policy scoped to single action and specific identity ARN</done>
</task>

<task type="auto">
  <name>Task 2: Scope CloudFormation DescribeStacks permissions</name>
  <files>cdk/lib/static-site-stack.ts</files>
  <action>
Update the GitHub Actions role CloudFormation policy (lines 131-136) to scope to the specific stack:

Change from:
```typescript
this.githubActionsRole.addToPolicy(
  new iam.PolicyStatement({
    actions: ['cloudformation:DescribeStacks'],
    resources: ['*'],
  })
);
```

Change to:
```typescript
this.githubActionsRole.addToPolicy(
  new iam.PolicyStatement({
    actions: ['cloudformation:DescribeStacks'],
    resources: [
      `arn:aws:cloudformation:${this.region}:${this.account}:stack/${props.siteName}-stack/*`
    ],
  })
);
```

Note: The `/*` at the end is required because CloudFormation stack ARNs include a unique ID suffix that changes on updates. The workflow queries by stack name (`--stack-name mitchellmeffert-website-stack`), and AWS resolves to the full ARN.
  </action>
  <verify>
Run `grep -A5 "cloudformation:DescribeStacks" cdk/lib/static-site-stack.ts` shows:
- Resource contains `stack/${props.siteName}-stack/*` (not `'*'`)
  </verify>
  <done>CloudFormation DescribeStacks scoped to specific stack ARN pattern</done>
</task>
