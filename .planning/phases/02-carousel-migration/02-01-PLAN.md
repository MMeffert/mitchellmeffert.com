  <files>js/custom.js, css/style.css</files>
  <action>
1. In js/custom.js, replace initClientSlider function (lines 133-144):
   ```javascript
   //ClientSlider
   ElvishApp.prototype.initClientSlider = function() {
       new Splide('#testimonial-carousel', {
           type: 'loop',
           perPage: 1,
           autoplay: true,
           interval: 7000,
           pauseOnHover: true,
           pauseOnFocus: true,
           arrows: false,
           speed: 1000,
       }).mount();
   },
   ```
   This matches original Owl config: 7s autoplay, pause on hover, single item, no arrows.
   Added pauseOnFocus for accessibility (WCAG compliance).
